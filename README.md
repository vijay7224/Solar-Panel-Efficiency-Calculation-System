☀️ Solar Panel Efficiency Calculation System

A system designed to calculate the efficiency of solar panels based on environmental and electrical parameters. This project helps analyze the performance of solar panels under different conditions and improves energy optimization.

🚀 Features

🌞 Calculates solar panel efficiency
📊 Takes real-time or manual input values
⚡ Uses electrical parameters (Voltage, Current)
🌡️ Considers environmental factors (Temperature, Sunlight)
🌐  Web interface using  Flask

🛠️ Tech Stack
Programming Language: Python
Frontend/UI: Flask
Libraries: numpy, pandas, Machine learning
